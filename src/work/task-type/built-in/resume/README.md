# Resume

The task of a ticket's assignee once the hand comes back to it: its requester answered its question or refused its delivery, or the founder gave it back the ticket it renounced. It is given the request and the messages that arrived since its last session on the ticket, and goes on as a handling does.

## Decisions

- [#145](https://github.com/OmarAboudou/AI-Company/issues/145): "Resume" (*Reprendre*), for the assignee, once the requester answered or refused the delivery.
