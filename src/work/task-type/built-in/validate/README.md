# Validate

The task of a ticket's requester once its assignee delivered it: it checks the delivery against the request, then validates it, which closes the ticket, or refuses it, saying what is missing. It validates even a delivery it made to itself, in a session of its own.

## Decisions

- [#145](https://github.com/OmarAboudou/AI-Company/issues/145): "Validate" (*Valider*), for the requester, once the assignee delivered; every delivery validated by its requester.
