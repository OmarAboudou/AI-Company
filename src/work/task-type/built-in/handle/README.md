# Handle

The task of a ticket's assignee once the ticket is created: its first session on the ticket. It is given the request, and delivers the ticket once the request is met, asks its requester a question it can't go on without, or renounces, saying what went wrong, if it can't meet the request.

## Decisions

- [#145](https://github.com/OmarAboudou/AI-Company/issues/145): "Handle" (*Traiter*), for the assignee of a ticket created.
