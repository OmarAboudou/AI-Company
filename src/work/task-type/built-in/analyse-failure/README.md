# Analyse the failure

The director's task once a task failed, which paused the company: from the failure's reason, and the discussion of the ticket the task worked on, it finds out what went wrong, readjusts what was missing with AICo's commands, then relaunches the company. It becomes pointless once the company is relaunched.

## Decisions

- [#145](https://github.com/OmarAboudou/AI-Company/issues/145): "Analyse the failure" (*Analyser l'échec*), for the founder, when a task fails and the company pauses.
