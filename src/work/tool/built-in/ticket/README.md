# Ticket tools

The tools that act on tickets, as `aico ticket` reads them: `ticket_show` shows a ticket's discussion word for word, its messages by their numbers, 20 at most per call, so that a long discussion never floods a run.

## Decisions

- [#123](https://github.com/OmarAboudou/AI-Company/issues/123): conversations stay readable word for word through tools.
- [#145](https://github.com/OmarAboudou/AI-Company/issues/145): a tool reads the messages of a ticket's discussion that a session's first message leaves out.
