# Messaging

How positions talk to each other: through threads, like posts in a forum, each a subject and a list of messages.

Threads are the company's archives: versioned in git, never modified once written, and read word for word by whoever works a task about them.

## Decisions

- [#56](https://github.com/OmarAboudou/AI-Company/issues/56): positions talk to each other through threads of immutable messages.
- [#135](https://github.com/OmarAboudou/AI-Company/issues/135): messages mention no position, and ask nothing of anyone for now.
