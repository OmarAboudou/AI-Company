# Messaging

How positions ask each other for work, and talk about it: through tickets, each a request from one position to another, with the discussion between the two.

Tickets and their messages are the company's archives: versioned in git, never modified once written, and read word for word by whoever works a task about them.

## Decisions

- [#56](https://github.com/OmarAboudou/AI-Company/issues/56): positions talk to each other through threads of immutable messages.
- [#135](https://github.com/OmarAboudou/AI-Company/issues/135): messages mention no position, and ask nothing of anyone for now.
- [#145](https://github.com/OmarAboudou/AI-Company/issues/145): tickets replace threads, their discussion keeping the messages as they were.
