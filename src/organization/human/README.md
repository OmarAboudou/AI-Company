# The human at the keyboard

The human at the keyboard is the user, who acts in a shell: the person git names.

They act from the positions they hold: the founder's position and every position no LLM employee holds. A position selected with `aico current-position set`, kept in the shell's environment until `clear`, narrows them to one, as an e-mail's From line does.

## Invariants

- The user writes, and works tasks, only from a position they hold, never on behalf of a position an LLM employee holds: they take it back first, so that authorship stays true.
- A selected position the user no longer holds is refused rather than replaced.

## Decisions

- [#56](https://github.com/OmarAboudou/AI-Company/issues/56): the people at the keyboard and the selected position.
- [#123](https://github.com/OmarAboudou/AI-Company/issues/123): people work their positions' tasks as LLM employees do.
- [#135](https://github.com/OmarAboudou/AI-Company/issues/135): the people working on the repository alone at the keyboard.
- [#145](https://github.com/OmarAboudou/AI-Company/issues/145): the directors become the user, who holds every position no employee holds.
