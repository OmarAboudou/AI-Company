# `aico message`

Writing in threads: `aico message send` adds a message to a thread, from the position you write from. It only writes: the tasks that listeners may create run in `aico run`, or wait for the people working their positions.

## Decisions

- [#56](https://github.com/OmarAboudou/AI-Company/issues/56): messages, and the position they are written from.
- [#123](https://github.com/OmarAboudou/AI-Company/issues/123): sending a message never runs a task.
