# `aico company`

The company's own commands: show it, update its name, pause and relaunch it; the project's description has commands of its own. `aico init` creates the company, with the director's position; no command deletes it, since AICo would have nothing left to work on.

## Decisions

- [#41](https://github.com/OmarAboudou/AI-Company/issues/41): the company can be updated, not deleted.
- [#136](https://github.com/OmarAboudou/AI-Company/issues/136): the project's description in place of the company's.
- [#145](https://github.com/OmarAboudou/AI-Company/issues/145): the founder pauses and relaunches the company by command.
